# LangChain Course Notes

Personal exercises from [Production AI Agents with LangChain + LangGraph](https://www.udemy.com/course/production-ai-agents/).

The repository covers LangChain fundamentals, RAG, memory, LangGraph workflows, human-in-the-loop interactions, and checkpointing.

```bash
cp .env.sample .env
uv sync
uv run python hitl.py
```

Add the required API keys to `.env`. Some examples use OpenAI, Anthropic, or LangSmith.
